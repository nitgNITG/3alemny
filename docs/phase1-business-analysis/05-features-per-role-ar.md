## ٧. الإعدادات القابلة للتخصيص

كل القيم دي هي الافتراضية — الأدمن يقدر يغيّرها من صفحة إعدادات الإضافة.

| الإعداد | الافتراضي | الوصف |
|---------|-----------|-------|
| مدة الحصة (دقائق) | `٥٠` | مدة كل حصة ثابتة بالدقائق |
| البوفر بين الحصص (دقائق) | `١٠` | الفاصل التلقائي بين الحصص المتتالية |
| أقل مدة إشعار للحجز (ساعات) | `١` | أقل وقت يقدر الطالب يحجز قبل الحصة |
| حد الإلغاء مع استرداد (ساعات) | `١` | قبله يرجع الكريدت، بعده يتخسر |
| خسارة الكريدت عند الإلغاء المتأخر | `مفعّل` | هل الكريدت بيتخسر لو الإلغاء متأخر |
| آخر وقت للتأجيل (دقائق قبل الحصة) | `٣٠` | آخر لحظة يقدر الطالب يأجّل فيها |
| أقصى حجوزات نشطة للطالب | `١٢` | الحد الأقصى للحجوزات الجاية للطالب |
| فترة السماح للدخول المتأخر (دقائق) | `١٠` | كام دقيقة بعد البدء الطالب يقدر يدخل |
| نسبة الحضور الدنيا (%) | `٧٠` | أقل نسبة تعتبر الطالب حاضر |
| المدرس يعدّل الحضور | `مفعّل` | هل المدرس يقدر يعدّل نتيجة الحضور |
| تعويض المدرس عند غياب الطالب | `مفعّل` | هل المدرس بياخد تعويض لو الطالب ما حضرش |
| عدد إلغاءات المدرس قبل تنبيه الأدمن | `٣` | الحد اللي بيجيله تنبيه للأدمن |
| الأدمن يقدر يمسح سجل الإنذارات | `مفعّل` | هل الأدمن يقدر يمسح إنذارات المدرس |
| الأدمن يتدخل يدوياً في الكريدت | `مفعّل` | هل الأدمن يرجع أو يخصم كريدت يدوياً |
| أيام الاحتفاظ بالتسجيل قبل الأرشفة | `٣٠` | كام يوم التسجيل بيفضل متاح للطالب |
| أقصى عدد مشاهدات للتسجيل | `٥` | كام مرة الطالب يقدر يشوف التسجيل |
| السماح بتحميل التسجيلات | `معطّل` | هل الطالب يقدر يحمّل التسجيل |
